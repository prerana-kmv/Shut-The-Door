🎯 Shut the Box — One Dice. One Chance. Shut it or Lose it.
A fast-paced twist on the classic Shut the Box game, built in C++ with SFML. You roll a single die, pick the right tiles that add up to the number, and shut them down. No second chances — miss a combo, and your turn's over.

🧠 Gameplay Rules (Simple & Savage):
🎲 Press Space to roll the die
🟩 Click tiles that add up to the dice number
⏎ Hit Enter to lock your move
🚫 No valid combo? You're out.

⚙️ Built With:
C++ (Core logic)

SFML (Graphics, animation, and good vibes)

🚀 Why This Project?
Wanted to build something fun and visual while keeping the logic clean and beginner-friendly. Perfect mix of coding + creativity.
